# 基础环境
 通过终端进入仓库文件夹，执行对应命令，它们会检查你的本机环境，发现缺失时，输入 `y` 表示同时，它会自动安装，否则退出，你可以手动安装。

### MacOS：

```shell
bash "系统服务/工具/macOS-check-env.sh"
```

### Windows：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\系统服务\工具\Windows-check-env.ps1"
```

出现“基础环境准备完成”后，继续安装你选择的 Agent CLI 产品和相关工具。

以下为 macOS 手动安装步骤。

## [Homebrew](https://brew.sh/)
macOS 常用的软件包管理工具，可安装其软件源提供的命令行工具和应用。
### 官方原版

```shell
# 安装（海外源，速度不稳定）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" 

# 配置
echo 'eval "$(brew shellenv)"' >> ~/.zshrc

# 激活
source ~/.zshrc
```

### 国内安装

```shell
# HomebrewCN（第三方社区安装脚本）
/bin/zsh -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)"
```

### 验证可用

```shell
brew doctor
# 检查安装，输出「Your system is ready to brew.」表示健康。

brew --version
# 输出版本号
```

## [Node.js](https://nodejs.org/zh-cn)
部分 Agent CLI 工具需要的运行环境。版本要求以所选工具的官方说明为准：

```shell
# 安装
brew install node

# 验证
node -v
npm -v
```

## [Git](https://git-scm.com/)
用于版本管理。即使工作区文件被删除也可恢复；让 AI 用它帮你把仓库备份到远程以确保数据安全：

```shell
# 安装
brew install git

# 验证
git --version
```

请自行选择 Agent CLI 产品（如 Codex、Claude、OpenClaw、DeepSeek Harness 等），根据官网提示完成安装，本仓库不做示范。

# 系统工具
## macOS 应用已损坏的处理方法
### 配置
 第一步：打开访达按 `shift+command+句号` 显示隐藏文件，找到 `.zshrc` 文件，用文本编辑打开，粘贴下方代码，保存后关闭文件。

```shell
function unquarantine() {
  if [ -z "$1" ]; then
    echo "用法：unquarantine 拖文件/应用到这里"
    return 1
  fi
  sudo xattr -c "$1"
  echo "✅ 已清除「$1」的隔离属性，现在可以打开了！"
}
alias uq='unquarantine'
# 可以用你习惯的任何字母组合替换alias（别名）后面的 uq 。
```

第二步：打开终端，输入下面的命令，让配置生效

```shell
source ~/.zshrc
```

### 使用
1. 打开终端输入 `uq` （注意末尾加一个空格，别漏！）；
2. 把要打开的软件从应用程序目录里拖到终端里的 `uq +空格` 的后面 → 回车；
3. 输入电脑密码（终端输入密码时不显示，正常输就行）→ 回车，搞定！

执行后终端会输出 `✅ 已清除...`。重新打开那个曾经显示已损坏的软件就正常了。

## MacOS 操作彩蛋：拖动窗口
按住 `control+command`，鼠标点击窗口任何位置即可选中并移动该窗口，不用像之前那样要选中窗口的顶部标签栏：

```shell
# 打开
defaults write -g NSWindowShouldDragOnGesture -bool true 

# 关闭
defaults write -g NSWindowShouldDragOnGesture -bool false
```
