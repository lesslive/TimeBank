## 关于 TimeBank
TimeBank 是一个为 AI 协作准备的个人仓库。把你与 AI 对话中确认的背景、想法和结论，存进预设的对应模块。后续协作时，让 AI 读取相关内容，就能接着已有的进展继续，不必每次从头讲起。
## 工作原理
### 首先结构化｜让生活井井有条
**把生活解构为边界清晰且彼此关联的模块，不再混乱和无序**

| 模块分类           | 资产类型      | 资产价值              |
| :------------- | :-------- | :---------------- |
| **第一课题：和自己相处** | 自我认知，稳定内核 | 不迎合、不讨好、不被外界裹挟的自我 |
| **第二课题：和世界相处** | 落地执行、行动管理 | 低成本、少依赖的谋生策略和外部环境 |
| **第三课题：和他人相处** | 建立关系、协作互动 | 把生意做成和一群人共同创建的生活圈 |

### 然后最小化｜让自己轻装上阵
**只保留确实需要且只需要的最少必要条件，扔掉包袱和消耗**
- [品牌故事设计](第二课题/能力/品牌故事设计/品牌故事设计.md)：用课题分离设计边界清晰的故事，避免讨好迎合而内耗
- [对外表达策略](第二课题/能力/对外表达策略/对外表达策略.md)：展示价值、汇报进度、提供服务，源源不断的内容选题
- [第一人称法则](第二课题/能力/第一人称法则.md)：从我，到我和你，再到我们一起，信手拈来的内容创作
- [AARRR-OKR](第二课题/能力/AARRR-OKR/AARRR-OKR.md)： 用生命周期管理目标与关键成果，每场战役都使命必达
- [服务设计思维](第二课题/能力/服务设计思维/服务设计思维.md)：建设中……
### 最后资产化｜把时间变成资产
**用作个人仓库，把实践的经验、财富和人脉沉淀为个人资产**
- 第一课题：沉淀认真思考过的内容，掌控自己的欲望、责任和边界
- 第二课题：沉淀和世界打交道的策略和方法，踩过的坑和吃过的亏
- 第三课题：沉淀与受众的互动和故事，见证社会资本的形成与累积

## 快速开始
### 1.  获得模板
- 克隆或下载到本地，用任何 markdown 工具即可使用
- 接入本地 AI agent（推荐）
- 推荐使用 obsidian 作为日常使用

### 3. 安装 Obsidian 插件（可选）
参考[插件说明](系统服务/指南/插件说明.md)，安装以下插件获得更好体验：
- **Make.md**：文件夹笔记和筛选
- **Dataview**：动态查询内容
- **Kanban**：可视化目标与任务看板

### 4. 开始使用
1. 阅读 `第一课题/第一课题.md`，了解如何和自己相处
2. 参考 `tags: [example]` 的示范内容，看作者如何使用
3. 在 AI 的协助下，开始构建你自己的 LessLive 模型


> 💡 仓库中带 `tags: [example]` 的内容，是我的真实生活记录，仅供参考，不构成任何效果保证或专业建议，使用风险自负。
