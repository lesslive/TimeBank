## 什么是 OPC.OS

OPC.OS 是面向独立个体的一人公司设计的运行系统（One-Person Company Operating System）。它通过结构化解耦、最小化卸负、资产化沉淀，帮助个人创业者统筹自己的工作、资源、关系，为持续飞行的“雨燕”构建低成本、少依赖的生存与生活环境。

## 关于 LessLive

我是一名个人创业者，但改变世界、拯救人类这种宏大叙事大概率轮不到我。作为一只一生都在飞行的鸟，我必须要卸掉负重。为此，我设计了 OPC.OS，用来管理我的生活和工作，帮我甩掉包袱，轻装上阵，可以飞得更高、更远：
- 回到自己真正热爱且擅长的领域，避免自己被宏大叙事所裹挟
- 拿掉消耗而非滋养自己的不必要，构建轻松的生存与生活环境
- 构建烟火气人情味十足的生活圈，不因工作而失去生活的本质

我把这种生活命名为：LessLive，最小化生活。

> 💡 仓库中带 `tags: [example]` 的内容，是我的真实生活记录，仅供参考，不构成任何效果保证或专业建议，使用风险自负。

## 核心特色
就像 AI 使用 Skill 知道怎么干活一样，这些模块是给人类使用的 Skill：
### 首先结构化｜让生活井井有条
**把生活解构为边界清晰且彼此关联的模块，不再混乱和无序**

|  课题分类          | 核心问题         | 主要产出              |
| :------------- | :----------- | :---------------- |
| **第一课题：和自己相处** | 如何看清自我，构建内核？ | 不迎合、不讨好、不被外界裹挟的自我 |
| **第二课题：和世界相处** | 如何落地目标、立足行动？ | 低成本、少依赖的谋生策略和外部环境 |
| **第三课题：和他人相处** | 如何建立关系、协作互动？ | 把生意做成和一群人共同创建的生活圈 |

### 然后最小化｜让自己轻装上阵
**只保留确实需要且只需要的最少必要条件，扔掉包袱和消耗**
- [品牌故事设计](第二课题/能力/品牌故事设计/品牌故事设计.md)：用课题分离设计边界清晰的故事，避免讨好迎合而内耗

- [第一人称法则](第二课题/能力/第一人称法则.md)：从我，到我和你，再到我们一起，信手拈来的内容创作
- [AARRR-OKR](第二课题/能力/AARRR-OKR/AARRR-OKR.md)：用生命周期管理目标与关键成果，每场战役都使命必达
- [服务设计思维](第二课题/能力/服务设计思维/服务设计思维.md)：建设中……
### 最后资产化｜把时间变成资产
**用作个人仓库，把实践的经验、财富和人脉沉淀为个人资产**
- 第一课题：沉淀认真思考过的内容，掌控自己的欲望、责任和边界
- 第二课题：沉淀和世界打交道的策略和方法，踩过的坑和吃过的亏
- 第三课题：沉淀与受众的互动和故事，见证社会资本的形成与累积

## 边界说明

✅ **LessLive 是：**
- 一套思维模型，用来构建自我内核、谋生手段、人际关系的运行系统；
- 一套 Markdown 文档，不限定编辑器；
- 一个沉淀个人成长经历的仓库设计架构。

❌ **LessLive 不是：**
- 不是 Obsidian 专属模板，任意 Markdown 工具均可使用；
- 不是拿来直接复制套用的现成知识库；
- 不是一套标准答案，不会替你做人生决策；
## 快速开始

### 1.  打开仓库（支持 Markdown 的工具）
- 下载仓库（克隆或下载）
- 使用 obsidian（推荐）
- 打开 LessLive 仓库目录
- 接入本地 AI agent（可选）

### 3. 安装 Obsidian 插件（可选）
参考[插件说明](系统服务/指南/插件说明.md)，安装以下插件获得更好体验：
- **Make.md**：文件夹笔记和筛选
- **Dataview**：动态查询内容
- **Kanban**：可视化目标与任务看板

### 4. 开始使用
1. 阅读 `第一课题/第一课题.md`，了解如何和自己相处
2. 参考 `tags: [example]` 的示范内容，看作者如何使用
3. 在 AI 的协助下，开始构建你自己的 LessLive 模型
