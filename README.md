## 关于 TimeBank
TimeBank 是一个存在你本地的 Markdown 仓库。把你和 AI 聊生活、工作、关系等得出的结论，存进对应的目录，形成纯净的上下文，下次再聊。AI 读到的是这些结论，而不是冗余杂乱的聊天记录。
## 工作原理

### 最小化｜存什么：只留下值得留下的
**从生存与生活的实践中，提炼并加工成值得留下的成果。**

一次思考、一段合作、一次尝试，都可能留下有价值的认知和成果。TimeBank 不追求原样收存所有记录，而是帮助你与 AI 一起梳理：哪些事实值得记住，哪些判断有了依据，哪些方法经过实践，以及哪些问题仍待验证。

例如，一次合作留下的，不只是聊天记录，还可以是明确的协作边界、问题产生的原因，以及复盘后形成的方法。保留支撑这些成果的必要背景，让经历成为能够理解、检查和继续使用的内容。

这些成果不再是散落的记录，接下来，还需要按照各自的职责组织起来。

---
### 结构化｜放哪里：每份资产各归其位
**把资产按三大课题分区存放，形成完整有序的上下文。**

| 结构       | 定位    | 职责                            |
| :------- | :---- | :---------------------------- |
| **第一课题** | 和自己相处 | 认识自己的意愿、立场与状态等自我画像，建立与外部世界的边界 |
| **第二课题** | 和世界相处 | 基于第一课题，设计行动策略、目标、计划，构建生存与生活环境 |
| **第三课题** | 和他人相处 | 基于前两个课题，在具体项目中形成面向他人的表达、交付与输出 |


- 第一、第二课题面向自己，用于自我的内部认识、研究、设计与规划。
- 第三课题面向明确的他人，包括对外合作方案、给家人的信、面向用户的推文等

---
### 资产化｜怎么用：持续增值形成复利
**让已有积累，成为下一次行动的基础，并不断累积更多优质资产。**

- **后续工作有起点**：再次思考、决策或与 AI 协作时，从已有认识和进展继续，不必重新梳理全部背景。
- **当前行动有依据**：面对新的机会、任务或对外表达，结合自己的意愿、策略和现实进展作判断，而不是每次临时起意。
- **用实践改进积累**：用实际结果检验原有判断，保留有效经验、修正失效认识，让下一次行动建立在更可靠的基础上。

资产的价值不止于被保存，而在于持续使用、接受现实检验，并在这个过程中不断完善。用得越多，它越准确，下一次的起点也越高，这就是资产的复利。

## 开始使用

### 1. 获取并打开仓库

将仓库克隆到本地；如果下载的是压缩包，解压后先建立 Git 版本管理。可以使用 Markdown 编辑器阅读和编辑，推荐用 Obsidian 打开仓库文件夹。

仓库中带 `example` 标签的文件是作者的真实实践，可以参考它们的组织方式与表达，但应根据自己的情况形成内容。示例内容仅供参考，不构成任何效果保证或专业建议，使用风险自负。

### 2. 接入 AI 助手

选择能够读取和编辑本地文件的 AI 助手，将仓库根目录作为工作目录，并让它先阅读 [AGENTS.md](AGENTS.md)。这份入口说明了如何理解仓库、按任务读取相关内容，以及如何与你协作。

### 3. 从一件真实的事情开始

不必先填满所有模块。告诉 AI 你现在想推进什么，让它结合相关内容与你讨论；如果缺少必要的认识或设计，先明确缺口，再一起决定从哪里补起。

可以这样开始：

> 请先阅读仓库根目录的 AGENTS.md。我现在想推进的是……，目前的情况是……。请按相关模块的职责协助我，已有背景先从仓库读取，不清楚的再问我。需要保存的成果，经我确认后再写入对应位置。

协作后，检查变更文件及内容，确认无误后再提交到 Git。同一份内容直接更新，修订历史交给 Git，不另存多个版本。

### 4. 下次接着已有进展继续

再次协作时，指出相关事项或文件，让 AI 读取已有背景、结论和进展。你只需补充尚未记录的变化，并确认旧内容是否仍然适用，就可以继续推进。

> 请按 AGENTS.md 的说明，读取与……有关的内容，先梳理已有结论和进展，再和我讨论下一步。

**可选：增强 Obsidian 的使用体验。** 需要文件夹笔记、动态查询或可视化看板时，可以按需参考[插件说明](系统服务/指南/插件说明.md)。插件配置不必成为第一次协作的前置任务。
