## 什么是 LessLive

LessLive 是一套**把朋友圈变成生活圈**的行动方案。它帮助你把生活、工作或者兴趣爱好，设计成一个具体的行动计划，吸引你的朋友、同事、家人和客户关注并参与进来，形成你的生活圈。

---

## 工作原理

LessLive 借鉴阿德勒心理学，运用服务设计思维，将个人生活组织为与自己、与世界、与他人相处的三大课题，把关系构建落实为可以研究、设计、执行和复盘的具体工作，并在实践中持续检验与完善。通过剔除消耗自己的不必要，构建滋养自己的生活圈。

### 结构化｜让生活井井有条

1️⃣ 将生活拆分为边界清晰且彼此关联的模块；
2️⃣ 让每件事都有适合它的归属和精准的位置。

| 结构       | 定位    | 职责                            | 目标                |
| :------- | :---- | :---------------------------- | :---------------- |
| **第一课题** | 和自己相处 | 整理自己的意愿、立场与状态等自我认知，建立与外部世界的边界 | 不迎合、不讨好、不被外界裹挟的自我 |
| **第二课题** | 和世界相处 | 基于第一课题，设计行动策略、目标、计划，构建生存与生活环境 | 低成本、少依赖的谋生策略和外部环境 |
| **第三课题** | 和他人相处 | 基于前两个课题，在具体项目中形成面向他人的表达、交付与输出 | 和一群人的有烟火气与人情味的生活圈 |

---

### 最小化｜让自己轻装上阵

1️⃣ 移除那些消耗和拖累自己的复杂性和冗余；
2️⃣ 从纷繁复杂的世界里，蒸馏出自己的生活。

**仓库内置工具包**：
- [品牌故事设计](第二课题/能力/品牌故事设计/品牌故事设计.md)：用课题分离设计边界清晰的叙事，避免讨好迎合陷入内耗。
- [对外表达策略](第二课题/能力/对外表达策略/对外表达策略.md)：展示价值、汇报进度、提供服务，让输出内容饱满且精彩。
- [第一人称法则](第二课题/能力/第一人称法则/第一人称法则.md)：从我，到我和你，再到我们一起，让受众看一场人生电影。
- [增长黑客OKR](第二课题/能力/增长黑客OKR/增长黑客OKR.md)：针对个人改良的目标与关键成果工具，让执行高效且有序。


---
### 资产化｜把时间变成资产

1️⃣ 把实践中的方法和经验，沉淀为个人资产；
2️⃣ 在持续使用中不断淬炼，凝结成人生财富。

- **后续工作有起点**：再次思考、决策或执行时，从已有成果和进展继续，不必每次都重新整理和设计。
- **当前行动有依据**：面对新的机会或任务，结合现实进展和前因后果作出判断，而不是每次临时起意。
- **用实践改进积累**：用实践结果检验行动方案，保留有效经验、修正错误方法，让下一次行动更可靠。

## 开始使用

最简单的方式：把这个页面的链接发给你的 AI，让它读完，然后照着做。或者：
- 下载或克隆仓库到本地
- 接入可编辑本地文件的 AI Agent（如 Codex、WorkBuddy、豆包工作等）
- 发送消息给 AI 助手，比如：
  
```
阅读 AGENTS.md 并开始工作。
```

- 说明：也可以自行阅读仓库文档内容，理解并应用，无需 AI 协助。
- 推荐：使用 obsidian 管理仓库，请参考作者的[插件说明](系统服务/指南/插件说明.md)并选择安装与配置，获得更好的交互体验。
- 声明：仓库中带 example 标签的文件是作者的真实实践，可以参考它们的组织与表达方式，但应根据自己的实际形成原创内容。示例内容仅供参考，不构成任何效果保证或专业建议，使用风险自负。

## 一个开放的社会实验

这是 LessLive 官方使用 LessLive 方法发起的行动计划，供你参考：
### 研究实践

你可以用 LessLive 方法，做生活的研究员，对自己的生活展开研究，探索个人生存与生活环境的最佳实践，并将成果保存到自己的仓库，成为自己的人生财富。

### 成果交流

把你的仓库部署到 LessLive 组织，向来自各领域的 LessLive 成员乃至整个 GitHub 用户展示你的行动计划和实践成果，和我们一起，交流经验、探讨问题、共同研究，这是属于你的生活圈。

- [去看看其他研究员们的仓库](https://github.com/lesslive)：进入他们的仓库认识他们
- [立即申请加入LessLive社区](https://github.com/orgs/lesslive/discussions/1)：同样的，让他们也认识你
