## 这是一个社会实验
把你的生活、工作或者兴趣和爱好，设计成一个行动计划，邀请你的家人、同事、朋友、客户以及合作伙伴参与进来，和他们一起构筑你的生活圈。

> [!multi-column] 
>
>> [!info]  **结构化**｜让生活井井有条
>> 1️⃣ 将生活拆分为边界清晰且彼此关联的模块；
>> 2️⃣ 让每件事都有适合它的归属和精准的位置。
> 
>> [!info]  **最小化**｜让自己轻装上阵
>>  1️⃣ 移除那些消耗和拖累自己的复杂性和冗余；
>>  2️⃣ 从纷繁复杂的世界里，蒸馏出自己的生活。
> 
>> [!info]  **资产化**｜把时间变成资产
>> 1️⃣ 把实践中的方法和经验，沉淀为个人资产；
>> 2️⃣ 在持续使用中不断淬炼，凝结成人生财富。

| 结构       | 定位    | 职责                            | 目标                |
| :------- | :---- | :---------------------------- | :---------------- |
| **第一课题** | 和自己相处 | 整理自己的意愿、立场与状态等自我认知，建立与外部世界的边界 | 不迎合、不讨好、不被外界裹挟的自我 |
| **第二课题** | 和世界相处 | 基于第一课题，设计行动策略、目标、计划，构建生存与生活环境 | 低成本、少依赖的谋生策略和外部环境 |
| **第三课题** | 和他人相处 | 基于前两个课题，在具体项目中形成面向他人的表达、交付与输出 | 和一群人构筑烟火气与人情味的生活圈 |
